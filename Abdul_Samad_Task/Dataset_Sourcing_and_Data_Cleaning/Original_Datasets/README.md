# Original Datasets

This directory contains the original datasets collected for the **AI Decision Intelligence** project. These datasets will be used for business data analysis and subsequent data cleaning and preprocessing.

## 1. Sales Dataset

- **Dataset Name:** Online Retail
- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online+retail)
- **Purpose:** Analyze sales transactions, product quantities, prices, and customer purchasing patterns.
- **Original Format:** Excel (`.xlsx`)
- **License:** CC BY 4.0 — attribution required.

## 2. Expenses Dataset

- **Dataset Name:** Sample Expense Report CSV
- **Source:** [HowToCSV](https://howtocsv.com/sample-expenses-csv/)
- **Purpose:** Analyze business expenses, categories, vendors, payment methods, and expense amounts.
- **Original Format:** CSV
- **Data Type:** Synthetic sample data; verify the source's current usage terms before redistribution.

## 3. Inventory Dataset

- **Dataset Name:** Sample Products CSV
- **Source:** [HowToCSV](https://howtocsv.com/sample-products-csv/)
- **Purpose:** Analyze product stock levels, prices, costs, and product categories.
- **Original Format:** CSV
- **Data Type:** Synthetic sample data; verify the source's current usage terms before redistribution.

## Important Notes

- Preserve original datasets without modifying their contents.
- Perform cleaning and preprocessing on separate copies.
- Record any missing values, duplicate records, data type corrections, and other changes in the data cleaning documentation.
- These datasets come from different sources and are not necessarily directly compatible or linked by common identifiers.
